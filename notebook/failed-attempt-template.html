Failed attempt: template

17 October 2026failed attemptmeta

A failed attempt is one specific thing that didn’t work, written down with enough detail that someone could tell whether it would fail for them too. It is not a claim that the approach can never work. Set "status": "failed attempt" in data/notes.json.

What I expected

The prediction, made before running anything, and why it seemed reasonable.

What I tried

The change itself and the conditions: hardware, model, workload, versions, and how it was measured. Link the code or measurements if they can be shared.

What happened

Only observations here: numbers, with units and how many runs they come from.

What I think explains it

The interpretation, kept separate from the observations so a reader can disagree with one and still use the other.

What I would try next

The next experiment, and what result would change the conclusion. If I come back to it, link the later note here.

Limits of this conclusion

Where this result stops applying: other sizes, other hardware, other settings that were not tested.
