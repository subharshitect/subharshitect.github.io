# subharshitect.github.io

Minimal single page site. Pure HTML and CSS. Clean, fast, and easy to extend.

## Quick start

1. Create a new public repo named **subharshitect.github.io** on GitHub.
2. Download this zip and extract its contents.
3. Commit all files and push to the repo root.
4. On GitHub: Settings → Pages → Build and deployment → **Deploy from a branch**. Pick `main` and `/`.
5. Wait for Pages to publish. Visit `https://subharshitect.github.io`.

## Edit the site

- Change text in `index.html`.
- Tweak styles in `assets/style.css`.
- Replace `assets/favicon.svg` if you want.

Optional ideas:
- Add `writing/` folder and link posts from the Writing section.
- Add `cv.pdf` to the root and link it from the header.
- Add a custom domain later via Settings → Pages → Custom domain.
